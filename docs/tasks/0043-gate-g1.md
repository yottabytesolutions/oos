# Gate step G1: move-aware ratchets and migration prerequisites

## Goal

Make the gate ready for the first migration step that moves code (M2.1), as
[migration G1](../architecture/migration.md#g1-gate-prerequisites) and
[development.md](../development.md) ("Planned in gate step G1") specify.

## Plan

Reserved paths: `xtask/`, `docs/development.md`, `ui/src/board/mod.rs` (the `boundary` test module only),
`.github/workflows/ci.yml`, `.githooks/`.

- Ratchet files per crate: `xtask/data/<crate>/{clippy,size,statics,unsafe,known,allow}.txt`; the base comparison
  reads the combined files of a base that predates the split.
- Move-aware validation: `xtask/data/moves.txt` (`<old key> -> <new key>`) on the branch; a listed item passes at
  its new key if it is not larger than the old one at the merge base; `cargo xtask ratchet --move` transfers the
  entries and empties the file.
- Coverage: a branch passes 0.5 points below the floor; the integrator raises floors after the merge.
- Function size in code lines (no blank or comment lines, ADR 0010); the ratchet values fall with it.
- Module rules over external crate paths (`forbid ui <module> oos_hal::dho`) and a `confine` rule (a path named only
  from listed modules), replacing the `board::boundary` test.
- A shrink-only count of `#[allow(clippy::disallowed_methods)]` (and `expect`) per crate.
- The known-failure listing: `#[ignore = "known: task NNNN"]`, shrink-only, naming an existing task that is not
  done.
- Each item with failing-first tests in `xtask`; development.md updated; full gate on the final commit.

Task 0040 (task commands) follows on its own branch unless it fits here.
