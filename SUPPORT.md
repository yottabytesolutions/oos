# Getting help

- **Questions:** [Discussions](https://github.com/yottabytesolutions/oos/discussions). Use Q&A for how-to questions,
  Ideas for proposals that are not ready for an issue, Show and tell for setups and results, and General for the rest.
- **Bugs and feature requests:** [open an issue](https://github.com/yottabytesolutions/oos/issues/new/choose) with
  the bug or feature form. Say which model and which OOS build.
- **Hardware findings:** how the scope behaves, measured or observed, or results from another model: use the issue
  form "Hardware finding". Say how you know.
- **Security issues:** never in public. See [SECURITY.md](SECURITY.md).

Before you ask, check the [README](README.md), the [wiki](https://github.com/yottabytesolutions/oos/wiki) and the
open issues. Leave out serial numbers, MAC addresses and licence keys.

OOS is maintained in spare time. There is no guaranteed response time.
