# Active setup overview

Status: proposal for owner approval, task 0064, under
[ADR 0038](../adr/0038-menus-and-parser.md). There is no legacy overview page. The field bindings below
are verified against code at merged `overhaul` c59b71d5 (2026-11-16); the page, opening paths and layout are proposed behaviour,
not an implemented or hardware-verified screen. [Menus](menus.md) defines the shared values, highlighting and
navigation. Requirement ids are retained from draft e9f7c30b. The Delta column tracks changed requirements separately
from the proposed behaviour; citations have all been refreshed to the merged base.

## Information and links

Every category is present, including Off states, so absence cannot be mistaken for unavailable or forgotten state.
Show only physically existing analogue channels. For unsupported hardware features say **Unavailable on this model**;
for an available inactive feature say **Off**. A linked card is navigation, never an enable/disable shortcut. Values
use the same reader, units, option identity and selected-value cue as the corresponding menu item (menus H1).

## Open questions for the owner

- **overview-30:** Approve Main > Acquisition > Overview in both bottom bars and the fit-dependent Setup top-bar opener. At larger text sizes,
  is the guaranteed Main entry sufficient if the direct opener cannot fit?
- **overview-31:** Approve the two-column priority/layout budget and exact-total plus “+N” summaries for crowded
  measurements, math and decoder banks. The design has not been rendered; maximum-content goldens are required.
- **overview-32:** Approve always-visible Off/unavailable categories rather than hiding inactive features, and the
  compact extra indicators for references/SIM, bus, LA, logger, zones and generator output, including left-out features.
- **overview-33:** Approve pure links, particularly Cursor Off staying Off, and inspection of decoder/math bank
  summaries without Overview altering the live selection. The implementation must define a menu-local inspection
  context while retaining the existing explicit bank selectors.
- **overview-34:** Confirm the short user-facing route labels (fast frames, records, roll, scan, segmented HW/SW)
  against the acquisition contract at M17. This document requires actual route status but does not equate every
  current adapter diagnostic string with a permanent user-facing enum.
- **overview-37:** Approve using the full standalone page budget in both Cards and Compact modes, with workspace
  chrome restored exactly on return; approve the distinct live-overlay, record-owner and SIM summaries.
