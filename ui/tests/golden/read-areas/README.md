# Read descriptor menu references

These host pictures were captured from the legacy Bandwidth, Magnetic and Double pulse read dispatch before its
replacement by descriptors. The comparison lives in `ui::menu::bandwidth::tests` and never updates references.

Each image contains four panel-sized menu captures: the owner menu (top left), its picker after settings change while
focus stays elsewhere (top right), Back to the owner (bottom left), and Close (bottom right). The blank Close panel
checks that the menu is gone. All three text sizes and DHO802, DHO804 and DHO924S capability profiles are covered.
These are synthetic host renders, not hardware verification.
